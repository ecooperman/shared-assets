shared-assets

This isn't an app - it's the shared look-and-feel host for every app under evancooperman.com. Every app links to:

  • theme.css - the shared design tokens (colors, spacing) and component styles (accordion cards, add-toggle forms, message toasts, modals, app-nav, buttons, forms).
  • theme.js - shared DOM/fetch/date/UI helpers (el, showMessage, fetchJSON, domainFromUrl, toISODate, wireAccordionToggle, openModal/ closeModal, buildNav, ...), exposed as window.Global. See README.md for the full list.
  • icons.js - the shared inline-SVG icon registry (ICONS + applyIcons()), for <span data-icon="name"> elements.

To change how something looks or behaves across every app at once, edit the file here and redeploy this one service - no other repo needs to change. See README.md in this repo for the full picture, and each consuming app's own static/style.css for what's genuinely app-specific and stays local.
